How to Find Our Server

Open ARK: Survival Ascended → Join Game → Unofficial → PvE → Search “The Wizards of Ark”.

If servers don’t appear:

  • Enable Show Player Servers
  • Disable Password Protected
  • Set Map Filter to All Maps
  • Set PvE/PvP Filter to PvE or All
  • Refresh the list

If still not showing, restart your game and try again.
