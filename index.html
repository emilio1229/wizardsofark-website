How to Find Our Server – The Wizards of Ark

-Jumping into the realm is easy!

  • Open ARK: Survival Ascended
  • Go to Join Game
  • Select the Unofficial Tab
  • Set Game Mode: PvE
  • Search: The Wizards of Ark
  • Make sure Password Protected is UNCHECKED

-If you don’t see the servers right away, refresh the list and double-check your filters.

  • Enable Show Player Servers
  • Disable Show Password Protected Servers
  • Set Map Filter to All Maps
  • Set PvE / PvP Filter to PvE (or All)
  • Make sure you are on the Unofficial Tab
  • Search The Wizards of Ark and press Enter
  • Click Refresh

-Still not showing? Restart your game and repeat the steps. If you’re still having trouble, open a ticket on Discord and an admin will help you.
