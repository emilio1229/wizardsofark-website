How to Find Our Server

  1. Open ARK: Survival Ascended → Join Game → Unofficial tab.
  2. Set Game Mode to PvE and search for The Wizards of Ark.
  3. Make sure "Password Protected" is unchecked and press Enter / Refresh if needed.

If you still can't see the servers, fully restart the game and open a support ticket on Discord.
