# Community Assets

Organised by category:

```text
events/   — event banners and posters
guides/   — guide cover images
builds/   — base / build showcases
media/    — screenshots and media thumbnails
```

Full guide: [docs/CONTENT.md](../../../docs/CONTENT.md)

Add the image file here, then reference it from `src/data/community.ts` using:

```ts
communityImagePath('events', 'weekend-titan-hunt.jpg')
```
